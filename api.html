API reference¶

Arrays that carry their dimension names and labels.

A LabelledArray holds one or more equally shaped arrays together with an ordered mapping of dimension name to unique labels, aligns and reduces over them, and converts losslessly to and from pandas or polars DataFrames.

Everything below is importable from the package root where the package re-exports it; the sections follow the module that defines each object.

labelled_array.adapters¶

Registry of DataFrame adapters.

Adding support for another DataFrame library needs only a new DataFrameAdapter subclass and a call to register_adapter().

class labelled_array.adapters.DataFrameAdapter[source]¶

Bases: Plugin

Adapter for one DataFrame library.

Adapters read columns as numpy arrays and assemble numpy arrays back into a frame; the reshaping between flat rows and a dense array is shared, so every library goes through the same code and produces the same result.

The one step a library may do itself is factorize(), where its own string handling beats a Python loop over an object array – as polars’ does, several times over. A native path must reproduce the numpy reference exactly, and the test suite holds it to that. pandas has none: its factorize is barely faster than the reference, and merges strings that differ only after a NUL character.

The index-related methods default to “this library has no index”, which is true of every DataFrame library except pandas.

labelled_array.backends¶

Registry of array backends.

Backends are registered by name and resolved either by name or by inspecting an array. Adding support for a new array library needs only a new ArrayBackend subclass and a call to register_backend(); nothing in the core needs to change.

sliding_window(arr, axis, window)[source]¶

Return the windows of length window along axis, as a new last axis.

The result has shape[axis] replaced by shape[axis] - window + 1 and one axis of length window appended, so reducing over -1 gives one value per complete window.

Notes

The default builds the windows by stacking shifted copies, which costs window times the memory of the input. A backend that can express them as a view – numpy’s sliding_window_view, torch’s unfold – should override this.

The LabelledArray container.

class labelled_array.core.LabelledArray(data, dims=None, mask=None, coords=None, attrs=None, backend=None, alt_dims=None, *, broadcast=False)[source]¶

Bases: ArithmeticMixin

One or more equally shaped arrays sharing named, labelled dimensions.

Every variable has the shape given by dims, so a cell is addressed by one label per dimension. Dimension labels, the presence mask and the coordinates are always held as numpy arrays; only the variables live on the array backend, which may be numpy, JAX or torch.

Parameters:

  • data (mapping of str to array_like) – Variables, each of shape dims.shape.

  • dims (Dimensions or mapping or sequence of (str, array_like), optional) – Dimension names and labels, in axis order. Defaults to a natural index per axis of the first variable.

  • mask (array_like of bool, optional) – Shape dims.shape, True where a source row existed. Cells that are False are omitted by to_dataframe(), which is what makes a round trip lossless for dtypes with no missing-value representation.

  • coords (mapping of str to array_like, optional) – Auxiliary labels of shape dims.shape, holding the values a natural index dimension stands in for.

  • attrs (dict, optional) – Free-form metadata, carried through operations unchanged.

  • backend (str or ArrayBackend, optional) – Array backend for the variables. Defaults to the backend of the first variable that a registered backend recognises, else numpy.

  • alt_dims (mapping, optional) – Alternative dimensions, layered on dims.

  • broadcast (bool, default False) – Accept variables and a mask with a length-1 axis wherever they do not vary, e.g. time to expiry as (date, expiry, 1) beside vols over (date, expiry, strike). Each is stored broadcast to dims.shape: a read-only zero-stride view in numpy, so the values are held once. dims must then be given, and every such array must have one axis per dimension; see Notes.

Raises:

DimensionError – If a variable, mask or coordinate does not match dims.shape, or if a variable, coordinate and dimension name collide.

Notes

Variable, coordinate and dimension names share one namespace, because a DataFrame column can only carry one of each.

broadcast=True is stricter than numpy’s rule, which aligns shapes from the right: there a (5,) array lands on the last axis of a (5, 5) array whichever dimension it meant. Requiring one axis per dimension makes the caller say which. Coordinates keep numpy’s rule, and broadcast without the flag.

A broadcast variable stays compact only until an operation builds a new array from it. transpose(), copy(deep=False) and, on the numpy backend, isel() and select() keep the broadcast axes broadcast (the sliced cell is a read-only view); a deep copy(), astype(), to_backend(), arithmetic and pickling materialise it. assign() and item assignment do not broadcast; pass np.broadcast_to(value, array.shape). from_dataframe() always builds full arrays. In torch the stored view is not read-only: writing one element through it changes every cell that shares it.

Examples

>>> import numpy as np
>>> la = LabelledArray({"w": np.arange(6).reshape(2, 3)},
...                    dims={"a": [1, 2], "b": ["x", "y", "z"]})
>>> la.shape
(2, 3)
>>> la["w"][0, 2]
np.int64(2)

Parameters:

  • indexers (mapping of str to scalar or array_like, optional) – Labels to keep, per dimension. Dimensions not named are kept whole.   • **kwargs – Alternative to indexers, as keyword arguments.

ffill(dim, limit=None)[source]¶

Return the array with the last present position carried forward along dim.

A cell the mask marks absent takes the value of the nearest present cell before it along dim, in label order, and becomes present itself. Filled cells have to become present: were they left absent, to_dataframe() would drop the very rows the fill was performed to create.

The fill is over the mask, not over NaN. A masked-in NaN is a real observation of nothing and is left alone, as everywhere else here.

Parameters:

  • dim (str) – Dimension to carry along.

  • limit (int, optional) – Carry at most this many positions past a present cell. Cells further than that stay absent. Unlimited by default.

Returns:

An instance of this class with the same dimensions and labels. Cells before the first present position along dim are untouched, and stay absent at their fill value. An array with no mask is fully populated, so it comes back unchanged.

Return type:

LabelledArray

Raises:

  • DimensionError – If dim is not a dimension of this array, or is a natural index: the padding cells a natural axis holds were never rows, and filling them would give each the label of its source, so the result could not round-trip through to_dataframe().

  • ValueError – If limit is less than 1.

Notes

Variables, coordinates and the mask are gathered together, so a filled cell’s coordinates name the cell its value came from rather than itself. For a real coordinate that is usually what you want – it is what says how stale the carried value is – but it does mean a coordinate varying along dim no longer matches that dimension’s label at a filled cell. For the coordinate a natural index stands in for it would be the cell’s whole identity, which is why a natural dim is refused.

The age of a carried value needs no new concept: take the mask before the fill, derive the age from it, and store it as a coordinate, which costs nothing because the age varies along dim alone:

present = curve.mask.any(axis=-1)
pos = np.arange(len(dates))
last = np.maximum.accumulate(np.where(present, pos, -1))
age = np.where(last >= 0, dates - dates[last], np.timedelta64("NaT"))
curve = curve.ffill("date")._replace(
    coords={**curve.coords, "fill_age": age[:, None]}
)

...     {"w": np.array([1.0, 0.0, 0.0])},
...     {"b": ["x", "y", "z"]},

>>> la.ffill("b")["w"].tolist()
[1.0, 1.0, 1.0]

Build a labelled array from a polars or pandas DataFrame.

Each dimension column contributes its sorted unique values as that dimension’s labels, and every value column becomes a variable of the resulting dense array. Cells no row populates are recorded in the mask and filled with a placeholder the dtype can hold.

Parameters:

  • df (polars.DataFrame or pandas.DataFrame) – Source frame; the library is detected, and the array built is the same whichever it is. A pandas (Multi)Index is moved into columns first.

  • cols (str or sequence of str, optional) – Columns to turn into variables; defaults to every column that is not a dimension.

  • dims (str or sequence of str, optional) – Columns identifying a cell, in axis order; defaults to the names of the frame’s index levels, which polars frames never have.

  • natural (str, sequence of str, or mapping of str to str, optional) –

    Dimensions to replace with a natural index. Each named dimension becomes <name>_idx, labelled by position within the other dimensions rather than by value, and its values are kept as a coordinate so the round trip restores the original column. This is what keeps a dimension whose labels are near-unique per group – dates, typically – from blowing the array up.

    A position is counted within each combination of the dimensions that are not natural plus the natural ones declared earlier. How it is counted is the dimension’s mode, given by the mapping form {name: mode}; a name or a sequence of names means "rows".

    "rows"

    Number the rows. The labels must be unique within the group, and a repeat raises rather than being numbered twice.

    "distinct"

    Rank the distinct labels, so rows sharing a label share a position. This is for a ladder shared by the rows beneath it: the expiries of a long option chain, which repeat once per strike.

  • alt (mapping of str to str, optional) – Columns to fold in as alternative dimensions, each mapped to the dimension it describes. The column must say one thing per entry of that dimension, and is stored once per entry rather than once per cell – which is what keeps a descriptive column from becoming a dimension of its own and leaving the array mostly empty. It cannot be tied to a dimension named in natural, whose labels are positions rather than values.

  • fill_value (scalar or mapping of str to scalar, optional) – Value for unpopulated cells, per variable. Defaults to default_fill_value() of the dtype: NaN, NaT or None where the dtype has a null, and otherwise a value that cannot pass for data – the minimum of a signed integer, the maximum of an unsigned one. The mask is what marks the cell absent; the fill is what anything reading the array without the mask will see, which matters most under mask=False.
