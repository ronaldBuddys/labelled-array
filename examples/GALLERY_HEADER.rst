.. _examples:

Examples
========

Runnable scripts. Each one executes top to bottom under plain ``python`` and also opens as
a notebook; the download links are at the foot of every page. The checks on each page are
assertions, and Sphinx-Gallery runs every page at build time, so a page that stops
matching the code fails the build, and the numbers shown were produced by the code, not
typed in.

Read the basics first. The performance page stands apart: its timings depend on the
machine.
