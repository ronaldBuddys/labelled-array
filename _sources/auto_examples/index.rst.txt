.. _examples:

Examples
========

Runnable scripts. Each one executes top to bottom under plain ``python`` and also opens as
a notebook; the download links are at the foot of every page. The checks on each page are
assertions, and Sphinx-Gallery runs every page at build time, so a page that stops
matching the code fails the build, and the numbers shown were produced by the code, not
typed in.

Read the basics first. The performance page stands apart: its timings depend on the
machine.

Layout
------

What an array holds besides its variables: the presence mask that records which cells
had a source row, a natural index that keeps a sparse panel dense, and alternative
dimensions that label a dimension the array already has.

  <div id='sg-tag-list' class='sphx-glr-tag-list'></div>

.. raw:: html

    <div class="sphx-glr-thumbcontainer" tooltip="A dense array has a cell for every combination of labels, whether or not the data had a row for it. The mask is how a LabelledArray remembers which cells are real. This example follows it from the frame it comes from, through every operation that changes it, and back out to a frame.">

  .. image:: /auto_examples/layout/images/thumb/sphx_glr_01_presence_mask_thumb.png

Replacing that dimension with a natural index collapses the array while keeping the original values, so the round trip is still exact.">
